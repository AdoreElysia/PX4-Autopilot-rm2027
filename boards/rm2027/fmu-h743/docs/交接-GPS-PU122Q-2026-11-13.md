# 交接：外置 GPS 普锐微 PU-122Q + 模块罗盘（2026-11-13）

## 0. 一句话

买了 UPRII（普锐微）PU-122Q GPS 一体模组：主芯片 **u-blox M10050（M10 平台）**，
内置 **QMC5883L** 罗盘。6 个焊盘丝印 **`G V T R C D`**（从左到右）。

- **GPS** 走 `UART7 = /dev/ttyS6`（对外座 **U18**）—— 零驱动代码，PX4 按协议自动识别
- **罗盘** 走**软件 I²C**（GPIO bit-bang）接到对外座 **U19** 的 PE0/PE1 —— 新写了 `qmc5883l_softi2c`

⚠️ **为什么不接板载 I2C4**：那条总线上只有 IST8310 本体的 LGA 焊盘、两颗 0402 电阻、
MCU 的 LQFP 引脚，**没有任何测试点或接插件**，物理上飞不出线来（见 §2.3）。

> **★ 当前阶段（2026-11-13）：只验证 GPS。**
> 罗盘驱动已编译进固件，但 `rc.board_sensors` 里的启动行**被注释掉了**，
> 开机不会碰 PE0/PE1。等 GPS 确认可用后，再按 §4.3 第 2 步单独启用罗盘。
> 所以现在只需接 **G / V / T / R 四根线到 U18**，C/D 可以先不接。

| 水平精度 | 2 m (CEP50) | DS 1.5 m CEP（多星座），厂商取保守值 |
| 冷启动 | ≤27 s | ✅ DS Table 2：GPS+GAL+BDS 27 s |
| 跟踪灵敏度 | -167 dBm | ✅ DS Table 2 |

### 1.3 ★ 引脚定义（唯一没有官方文档的部分）

122Q 背面 6 个焊盘，**从左到右**：

```
G    V    T    R    C    D
```

| 丝印 | 含义 | 接到 | 座引脚 |
|---|---|---|---|
| **G** | GND | GND | U18.4 |
| **V** | VCC（3.3–5 V） | 5V | U18.1 |
| **T** | TX（模块发） | UART7_RX = PE7 | U18.2 |
| **R** | RX（模块收） | UART7_TX = PE8 | U18.3 |
| **C** | SCL | PE0（软 I²C SCL） | U19.2 |
| **D** | SDA | PE1（软 I²C SDA） | U19.3 |

⚠️ **T/R 交叉**：模块 TX → 飞控 RX，模块 RX → 飞控 TX。接反不烧，但收不到数据。

## 2. 接线

### 2.1 GPS：U18 座（UART7）

```
模块 G  ──→  U18.4 (GND)
模块 V  ──→  U18.1 (5V)
模块 T  ──→  U18.2 (PE7, UART7_RX)      ← 交叉
模块 R  ──→  U18.3 (PE8, UART7_TX)      ← 交叉
```

### 2.2 罗盘：U19 座（原 UART8，现作软 I²C）—— **当前阶段先不接**

```
模块 C (SCL) ──→  U19.2 (PE0)
模块 D (SDA) ──→  U19.3 (PE1)
```

**注意：现在只测 GPS，这两根先别接。** 空着不影响 GPS，也避免多一个变量。
等 GPS 验证通过后，再接这两根、跑 `qmc5883l_softi2c test`。

⚠️ **代价**：UART8 / ttyS7 从此不可用，ESC4 串口遥测没了（当前本来就没启用）。
   即使罗盘驱动不启动，UART8 也回不来（defconfig 里已关）。

### 2.3 ⚠️ 为什么不能用板载 I2C4（重要）

网表里 I2C4 两个网络的**全部**焊点：

```
IIC4_SCL  →  R20.1(0402 电阻) · U1.59(MCU LQFP 脚) · U2.1(IST8310 的 LGA-16 焊盘)
IIC4_SDA  →  R2.1 (0402 电阻) · U1.60(MCU LQFP 脚) · U2.16(IST8310 的 LGA-16 焊盘)
```

依据：`work/FMU2-引脚识别-20261030/netlist-FMU_1.txt:113-114`
+ 原理图 `references/硬件手册/fmu_2026-09-24.pdf` 的 MAG 区块。

- U2 是 **IST8310 芯片本体**（LGA-16，约 2×2 mm，焊盘全在底下）
- R20/R2 是 **0402 电阻**（约 1×0.5 mm）
- U1.59/U1.60 是 **LQFP100 的细脚**

**这三样都不是能手焊的东西**，而 5 个对外 GH1.25-4P 座（U17/U18/U19/U20/U21）
只有 5V/GND/TX/RX 四根线，**没有 SCL/SDA**。

⇒ 这条总线只服务于焊死的 IST8310，**物理上无法外接**。
   所以 `src/i2c.cpp` 里它保持 `initI2CBusInternal(4)`，**不要改成 Shared**。

## 3. 代码改了什么

### 3.1 GPS 部分（3 行配置，零驱动代码）

`default.px4board`：
```
CONFIG_BOARD_SERIAL_GPS1="/dev/ttyS6"   # UART7 / U18
CONFIG_DRIVERS_GPS=y                     # 之前根本没编进去！
CONFIG_GPS_UBX=y                         # 只编 UBX，省约 20KB
```

**为什么够了**：PX4 的 GPS 驱动**按协议识别，不按型号**：

1. `src/drivers/gps/gps.cpp:118-134` 的 `kAutoDetectModes` 依次试 UBX → MTK → ...
2. M10050 说标准 UBX，第一轮就命中
3. 接着读 `MON-VER` 的 `hwVersion="000A0000"`，自己认出是 M10
   （`ubx.cpp:2455-2476` 的 `known_boards` 表）
4. M10 专属处理：NMEA@9600 抢占 ACK 时等 2 s（`ubx.cpp:206`）
5. 波特率自动扫：`ubx.cpp:142` 的
   `{38400, 57600, 9600, 115200, 230400, 460800, 921600}`，
   目标 115200（`ubx.h:246`）—— 与本模块出厂值天然一致

**自动启动链**：
`CONFIG_BOARD_SERIAL_GPS1` → 构建时生成 `GPS_1_CONFIG=201`
→ `rcS:601-603` 执行 `rc.serial` → 模板发现非 0 就自动跑
`gps start -d /dev/ttyS6 -b p:SER_GPS1_BAUD`
（`SER_GPS1_BAUD` 默认 0 = 自动探测）
⇒ **所以 `rc.board_sensors` 里故意不写 `gps start`**，写了会起第二个实例抢串口。

### 3.2 罗盘部分：新驱动 `qmc5883l_softi2c`

**新文件**（4 个）：
```
src/drivers/magnetometer/qmc5883l_softi2c/
    CMakeLists.txt
    Kconfig
    QMC5883LSoftI2C.hpp          ← 驱动主体
    QMC5883LSoftI2C.cpp
    qmc5883l_softi2c_main.cpp    ← 命令行入口 + 引脚实现
src/lib/softi2c/                 ← SoftI2C 从 vl53 目录**移出来**成公共库
    CMakeLists.txt
    SoftI2C.hpp
    SoftI2C.cpp
```

**为什么必须新写**：上游 `qmc5883l` 继承 `device::I2C`，只能挂硬件 I²C 总线。
本板插座上没有硬件 I²C，只能 GPIO bit-bang。

**与上游的对应关系**（这些都是逐条对齐的，不是重新设计）：

| 项目 | 上游 `QMC5883L.cpp` | 本驱动 |
|---|---|---|
| CNTL1 | `ODR_50HZ \| Mode_Continuous`，清 `OSR_512\|RNG_2G` | 同 |
| CNTL2 | `ROL_PNT`，清 `SOFT_RST` | 同 |
| SET_RESET_PERIOD | `0x01` | 同 |
| 标度 | `1/12000`（±2 G） | 同 |
| 轴向 | X, −Y, −Z | 同 |
| 复位后 POR 等待 | 100 ms | 同 |
| CHIP_ID 校验 | 要求 0xFF | 同（`probe` 里做） |

**唯一区别**：字节怎么送出去（`SoftI2C::write_read` 而不是 `device::I2C::transfer`）。

**SoftI2C 为什么抽成公共库**：现在有两个使用者
（`vl53l0x_softi2c` 和 `qmc5883l_softi2c`），放驱动目录里会变成两份各自演化的代码。
抽到 `src/lib/softi2c/` 后只有一个来源，`vl53l0x_softi2c` 的 include 也一并改了。

### 3.3 板级配置

| 文件 | 改动 |
|---|---|
| `src/i2c.cpp` | I2C4 保持 `initI2CBusInternal(4)`，补注释说明为什么不能外接 |
| `src/board_config.h` | 新增 `BOARD_QMC5883L_SOFTI2C_{SCL,SDA}_PINSET` = PE0/PE1 |
| `nuttx-config/nsh/defconfig` | **关闭 `CONFIG_STM32H7_UART8`**（PE0/PE1 要给软 I²C） |
| `init/rc.board_sensors` | 加 `qmc5883l_softi2c start -X` |

⚠️ **关闭 UART8 是安全的**：它是 `g_uart_devs[]` 数组的**最后一格**
（`stm32_serial.c:1495-1498`），而 ttyS 编号按数组顺序递增分配
（`stm32_serial.c:3934-3955`）。
⇒ 关掉最后一格**不会让 ttyS0..ttyS7 任何一个前移**。
这与"关 USART1 会让全部编号前移 1 位"（`board.h:394-400` 记的那个坑）完全不同。

### 3.4 `-X` 的含义

`qmc5883l_softi2c start -X` 的 `-X` **不是硬件总线过滤**
（软件 I²C 没有总线号），只用来给 `PX4Magnetometer` 打 external 标记：

1. `SENS_MAG_AUTOROT`（默认 1）**只对外部罗盘**自动解算安装方向，
   它会拿内部罗盘当参考 —— 本板的内部参考就是 IST8310
   （`src/modules/commander/mag_calibration.cpp:739-757`）
2. 外部件默认校准优先级 75 > 内部 50（`bus_topology.h:50`）

### 4.3 上板验证步骤

**第 0 步：先跑自检**（接线完、上电后，驱动还没起）

```
qmc5883l_softi2c test
```

它依次检查并打印大白话结论：
1. 引脚能否拉低、放开能否被上拉拉回高（查线断/没供电/上拉缺失）
2. 0x0D 有没有 ACK（查地址或 SDA/SCL 接反）
3. CHIP_ID 是不是 0xFF（查是不是 QMC5883P 等不同芯片）

**第 1 步：GPS**

```
gps status
```
期望：`port: /dev/ttyS6, baudrate: 115200, status: OK`

```
listener sensor_gps
```
期望：`num_satellites > 0`、`fix_type` = 3/4。

⚠️ **必须室外开阔天空**。这颗芯片冷启动约 27 s，室内即使开窗也常只有 0–3 颗星，
绿灯常亮不闪 = 未定位（正常现象，不是坏了）。首次定位可能要 1–3 分钟。

**第 2 步：罗盘（等 GPS 通过后再做）**

前提：先把模块 C/D 接到 U19.2 / U19.3（PE0/PE1）。

先自检接线，驱动**必须处于停止状态**（开机默认就是停的）：

```
qmc5883l_softi2c test
```
它会依次打印三步，每步都有大白话结论：
1. `pins : SCL OK, SDA OK` —— 线通、有上拉、模块有供电
2. `address : 0x0D ACK` —— 地址对、没接反
3. `chip id : 0xFF` —— 确认是 QMC5883L（不是 QMC5883P）

三步都过再启动：

```
qmc5883l_softi2c start -X
qmc5883l_softi2c status
```
期望：`state: READ`，`bus errors: 0`

```
listener sensor_mag
```
期望：三个轴都有数据，且**转动飞控时数值跟着变**。

**第 3 步：磁罗盘标定（罗盘启用后）**

QGC → 传感器校准 → 磁罗盘 → 开始。
`SENS_MAG_AUTOROT=1` 会自动解算外置罗盘的安装方向（拿 IST8310 当参考）。
若标定后报方向不一致，再回 `rc.board_sensors` 调 `-R`。

**要让罗盘永久自动启动**：取消 `rc.board_sensors` 里
`qmc5883l_softi2c start -X` 那行的注释，重新编译刷机。

                     src/drivers/distance_sensor/vl53l0x_softi2c/SoftI2C.hpp
